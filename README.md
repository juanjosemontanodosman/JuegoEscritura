# Juego de Escritura Rápida

Juego diseñado para la clase de Programación Orientada a Eventos.

El usuario recibe palabras seleccionadas aleatoriamente y debe escribirlas en un tiempo determinado, cada vez menor

## Cómo descargar el proyecto

Ejecuta el siguiente comando en una terminal:
```
git clone https://github.com/juanjosemontanodosman/JuegoEscritura.git
cd juegoescritura
```
