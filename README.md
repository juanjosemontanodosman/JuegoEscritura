# Escritura Rápida

Mini proyecto 1 de Fundamentos de Programación Orientada a Eventos (750014C) - Universidad del Valle.

Juego en JavaFX donde hay que escribir la palabra que sale en pantalla antes de que se acabe el tiempo. Cada vez que aciertas subes de nivel, y cada 5 niveles el tiempo baja 2 segundos (empieza en 20 y el mínimo es 2). Si se acaba el tiempo y la palabra está mal escrita, pierdes.

## Cómo ejecutarlo
1. Abrir el proyecto en IntelliJ.
2. Esperar a que Maven descargue las dependencias.
3. Ejecutar la clase Main (src/main/java/com/example/fastwriting/Main.java).

## Tecnologías
- Java 17
- JavaFX 21
- Scene Builder
- Maven
